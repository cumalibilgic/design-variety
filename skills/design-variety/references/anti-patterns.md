# AI-look tells and replacements

| Tell | Why it reads as generic | Do instead |
|---|---|---|
| Purple/indigo-to-blue gradient | The single most common AI palette | Pick a palette from the brief; flat colors are fine |
| Inter / Roboto / system-ui only | Zero typographic voice | Distinctive display font + quiet body font |
| Centered hero, H1, subtitle, two buttons | Every template ever | Split, asymmetric, or poster composition |
| 3 equal cards: icon, title, text | Filler structure | Unequal bento, numbered list rows, or one big feature |
| `rounded-2xl` + soft shadow everywhere | One radius, one depth, no character | Pick ONE radius language per direction (0, pill, or notch) |
| Emoji / generic line icons as decoration | Cheap and identical | Custom SVG shapes, numerals, or no icons |
| "Trusted by" logo strip with fake logos | Fake social proof | Remove, or real stats with personality |
| Gray-50 page, white cards | No atmosphere | Use the brief's background, add texture or color bands |
| Glassmorphism on every panel | Overused | Max one glass surface, only if the direction calls for it |
| Fade-up on every element | Motion without intent | One orchestrated load sequence + purposeful hovers |
| Lorem ipsum / "Feature One" | Looks unfinished | Write real, specific copy |
| Identical button style for all actions | No hierarchy | Primary / secondary / quiet, clearly different |

## Self-test

Cover the logo. If someone could not tell this page from 20 others you've built, change the direction, not the details.
